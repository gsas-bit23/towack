# Towack (TWAK)

Agent ID-gated mint, lucky draw, and trading router on BNB Chain.

This repository is a work in progress for the Binance Wallet × BNB Chain Agent ID Hackathon. Contracts are being developed and tested on **BSC testnet only**. No mainnet deploy yet.

Ticker: **TWAK**. The name Towack is not an existing crypto token (a 2020 music event used a similar name; this project is unrelated).

See `STATUS.md` for current progress.
